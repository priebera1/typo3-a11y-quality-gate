=====
Usage
=====

AQG is used in three places: in the content editors while writing (CKEditor,
plain HTML and image fields), in the :guilabel:`Page` module and backend
toolbar for a quick status, and in the :guilabel:`Accessibility` backend module
when reviewing, fixing and reporting findings.

For editors
    Start with :ref:`usage-ckeditor` and :ref:`usage-images`: how to recognise
    a warning, read How to fix, correct link text, headings and images, ask for
    optional AI help and confirm that a correction worked.

For administrators and accessibility leads
    :ref:`usage-overview`, :ref:`usage-page-detail`, :ref:`usage-ai-fixes`,
    :ref:`usage-remote-scans` and :ref:`usage-reports` cover scanning,
    reviewing, AI fixes, frontend scans and exports.
