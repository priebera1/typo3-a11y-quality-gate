# Support

## Where to get help

### Installation and usage questions

Use [GitHub Discussions — Q&A](https://github.com/priebera1/typo3-a11y-quality-gate/discussions/categories/q-a).

### Bugs and false positives

Open a [GitHub Issue](https://github.com/priebera1/typo3-a11y-quality-gate/issues/new/choose) using the appropriate template.

### Documentation

Read the [AQG documentation](https://typo3.priebera.sk/docs).

### Licensing and billing

Contact us through [AQG Support](https://typo3.priebera.sk/contact).

### Security vulnerabilities

Do not report security issues publicly. Use [GitHub private vulnerability reporting](https://github.com/priebera1/typo3-a11y-quality-gate/security/advisories/new) or email **support@priebera.sk**. See [SECURITY.md](SECURITY.md).

## What not to share publicly

Do not post client domain names, email addresses, licence keys or screenshots with private data in GitHub Issues or Discussions.
