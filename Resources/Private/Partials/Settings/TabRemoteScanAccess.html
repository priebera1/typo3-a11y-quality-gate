Excluded URL patterns

URLs the remote crawler should skip. Use this for admin areas, file folders, internal tools and other paths that should never be scanned.

Matching URLs will not be crawled. Examples: /fileadmin/* skips every file path; /preview?token=* skips preview URLs.

Priority URLs

Pages the remote crawler scans first. Use this for the homepage, contact page and other high-traffic pages — so issues appear in the report early.

Other URLs are still crawled in their normal order — this list only affects ordering, not visibility.
