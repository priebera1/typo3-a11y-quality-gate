How the Quality Gate decides which configuration to use
  1. Editor presses Save & publish or unhides the page.
  2. AQG looks for a site-specific configuration matching the page's site.
  3. If none exists, it falls back to the global configuration.
  4. If neither exists, the Quality Gate is disabled for that page.
  5. Open issues are compared against the matching thresholds; mode determines whether AQG warns or blocks.
