# Security Policy

## Supported versions

Security fixes are provided for the latest stable AQG release.

Older release lines may no longer receive security updates. Users should update to the latest stable version before reporting a problem.

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Use GitHub private vulnerability reporting instead:

**[Report a vulnerability privately](https://github.com/priebera1/typo3-a11y-quality-gate/security/advisories/new)**

Or email: **support@priebera.sk**

Include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- AQG version and TYPO3 version affected

We aim to acknowledge security reports within 5 business days.

Remediation and disclosure timelines depend on the severity, impact and complexity of the vulnerability. We will keep the reporter informed while the issue is being investigated.

We appreciate responsible disclosure.
